# Pots of Gold Screen

React frontend for the Pots of Gold game.

## Stack

- React 18
- Create React App
- Testing Library

## Run

```bash
npm install
npm start
```

Open `http://localhost:3000` in the browser.

## Scripts

- `npm start` starts the development server.
- `npm test` runs the test suite.
- `npm run build` creates a production build.

## Notes

The app currently calls the deployed API at `https://pog-api.shuttleapp.rs/api`.
