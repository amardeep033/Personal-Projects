# Personal-Projects

This repository contains multiple personal software projects, each maintained in its own folder.

## Projects

### Insta Place

A split frontend and backend JavaScript application built with React, Express, and MongoDB.

- Frontend: React client application
- Backend: Express API with routes for users, places, uploads, and authentication
- Project README: [insta-place/README.md](insta-place/README.md)

### Transaction Service

A Rust-based service for account and transaction APIs with webhook support.

- Built with Rust
- Includes database initialization scripts, Docker setup, and API documentation
- Project README: [transaction-service/README.md](transaction-service/README.md)
